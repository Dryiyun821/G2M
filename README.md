# G2M
This repository contains computational analysis workflows supporting a study of G2/M checkpoint-associated cellular states and treatment response in non-small cell lung cancer (NSCLC) undergoing neoadjuvant chemoimmunotherapy.

The analyses integrate bulk RNA sequencing, single-cell RNA sequencing, spatial transcriptomics, functional enrichment, survival analysis, and cell–cell communication inference to investigate TPX2-positive epithelial cells, proliferative MARCO-positive myeloid cells, and their potential contributions to therapeutic resistance.

The code is provided to facilitate reproducibility and further investigation of tumor cell proliferation and epithelial–myeloid interactions.
